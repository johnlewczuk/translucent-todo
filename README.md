# translucent-todo

A translucent, frameless, always-on-top nested todo overlay for Linux.

> The current implementation is being rewritten in Tauri (Rust + Svelte) for
> a single-binary distribution and richer styling. The original GTK4 + Python
> implementation lives in [`legacy-gtk/`](legacy-gtk/) and remains functional.

See [`docs/specs/2026-05-15-translucent-todo-tauri-design.md`](docs/specs/2026-05-15-translucent-todo-tauri-design.md)
for the active design.
